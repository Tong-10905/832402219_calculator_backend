# Code Style Guide

This document defines the coding conventions for the calculator backend project.

## Java

- Use PascalCase for class names, e.g. `CalculatorController`.
- Use camelCase for variable and method names, e.g. `calculateResult`.
- Use UPPER_SNAKE_CASE for constants, e.g. `MAX_VALUE`.
- Use 4 spaces for indentation.
- Put the opening brace `{` on the same line as the statement.
- Write one class per file, named after the class.

## Methods

- Keep methods short; each method does one thing.
- Use descriptive names, e.g. `addNumbers` instead of `func1`.
- Add comments for non-obvious logic.

## Git Commits

- Write short, clear commit messages, e.g. "Add calculation service".
- One logical change per commit.
